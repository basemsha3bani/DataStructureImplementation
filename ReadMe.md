# DataStructureImplementation

A repo of Abstract Data Types and Practice Problems implemented in C# from scratch.

## 📦 What's Inside
- **ADTs**: Generic `BinarySearchTree<T>`, `Stack<T>`, `Queue<T>`
- **Practice Problems**: 
    - `SpellChecker`: Dictionary lookup using BST + "Did you mean?" with Levenshtein Distance

## 🛠️ Tech Stack
`C#` `.NET 8` `File IO` `Algorithms` `Data Structures`
